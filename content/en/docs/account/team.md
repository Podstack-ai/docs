# Team

Everything you launch belongs to a project. A personal project is created when you sign in. Create more from [Team](https://podstack.ai/app/team) or from the project switcher (**Create a project**).

People in a project share instances, SSH keys, secrets, and one wallet.

## Invite

Invite by email. They join when they sign in with that address.

## Roles

| Role | Can |
| --- | --- |
| Owner, admin | Invite and remove people, rename the project, create a full-access API key. |
| Member | Use the project. Cannot create a full-access API key. |
| Viewer | Read. Cannot launch, change, or spend. |

Switch projects from the menu at the top of the sidebar. The balance shown in the header is the current project's wallet.
