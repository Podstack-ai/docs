# Getting started

These guides match the console at [podstack.ai/app](https://podstack.ai/app).

1. [Create an account](/docs/getting-started/creating-account/) with Google, Microsoft, or GitHub.
2. Open [Billing](/docs/billing/wallet/) and add credits. Cards, UPI, and netbanking go through Razorpay.
3. Add an [SSH key](/docs/account/ssh-keys/) before you launch a machine.
4. [Launch a GPU](/docs/gpu-cloud/launch-a-pod/), or call a model from [Inference](/docs/inference/quickstart/).
5. Install the [CLI](/docs/cli/) or the [Python SDK](/docs/sdk/) when you want the same actions from a terminal or a script.

The [console map](/docs/getting-started/console/) lists every product in the sidebar. [CLI, SDK, or MCP](/docs/guides/cli-sdk-mcp/) says which surface to use.
