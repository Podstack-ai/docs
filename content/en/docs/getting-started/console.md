# Console

The sidebar at [podstack.ai/app](https://podstack.ai/app) is grouped like this.

## Compute

| Item | Use it to |
| --- | --- |
| [GPU Cloud](/docs/gpu-cloud/) | See GPUs you can launch right now. |
| [Instances](/docs/gpu-cloud/instances/) | SSH into machines you launched, and terminate them. |
| [Watchlists](/docs/gpu-cloud/watchlists/) | Hear when a GPU frees up or the price drops. |
| [Schedules](/docs/gpu-cloud/schedules/) | Turn machines on and off, or delete them on a rule. |
| [Jobs](/docs/jobs/) | Run a script until it finishes. |
| [Reservations](/docs/reservations/) | Request a quote for 16 to 1,024 GPUs. |

## AI services

| Item | Use it to |
| --- | --- |
| [Inference](/docs/inference/) | Call hosted models. Pay per token. |
| [Functions](/docs/functions/) | Run a Python function on a GPU when it is called. |
| [Endpoints](/docs/endpoints/) | Serve a Hugging Face model on dedicated GPUs. |
| [Deploy](/docs/deploy/) | Launch a ready-to-run app. |

## Account

| Item | Use it to |
| --- | --- |
| [SSH keys](/docs/account/ssh-keys/) | Log into instances. |
| [Secrets](/docs/account/secrets/) | Store values jobs can read. |
| [Billing](/docs/billing/) | See the wallet and add credits. |
| [Team](/docs/account/team/) | Share a project. |
| [API keys](/docs/account/api-tokens/) | Call `https://podstack.ai/api/v1`. |
| [Support](/docs/support/) | Open a ticket. |
| [Settings](/docs/account/settings/) | Rename the project and set your location. |

The project switcher at the top of the sidebar chooses which project you are spending. The balance next to it is that project's wallet. A product can be turned off for the platform; if it is, it disappears from the sidebar.
