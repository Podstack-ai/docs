# Watchlists

[Watchlists](https://podstack.ai/app/watchlists) notify you when a scarce GPU frees up or the price drops.

Create a watch, pick a GPU, choose **becomes available** or **price drops below**, and optionally a region. Podstack emails you when the rule matches.
