# Schedules

[Schedules](https://podstack.ai/app/schedules) turn machines on and off, or delete them.

**On/off.** Pick days, an on time, and an off time. Off deletes the machine and its disk. On launches a fresh machine from the saved setup.

**Deletion rules.** Delete one instance, or every instance, at a clock time, after it has run a number of hours, or once it has cost a set amount.

Open a schedule from the calendar control on an [instance row](/docs/gpu-cloud/instances/).
