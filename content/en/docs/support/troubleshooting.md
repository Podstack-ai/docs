# Troubleshooting

- Instance will not launch or SSH fails: [GPU Cloud troubleshooting](/docs/gpu-cloud/troubleshooting/).
- A job fails or has no logs: [Jobs troubleshooting](/docs/jobs/troubleshooting/).
- A `ps_live_` key is rejected: [API keys](/docs/account/api-tokens/). The token must start with `ps_live_`. The base URL is `https://api.podstack.ai/v1`.
- A request returns 402: the project wallet cannot cover it. [Add credits](/docs/billing/wallet/).
