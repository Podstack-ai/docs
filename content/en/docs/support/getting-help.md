# Getting help

- Console: [podstack.ai/app/support](https://podstack.ai/app/support). Include the instance or job id.
- Email: [support@podstack.ai](mailto:support@podstack.ai).

Trust and compliance statements are on [podstack.ai/trust](https://podstack.ai/trust). Terms, privacy, and refunds are linked from the site footer.
